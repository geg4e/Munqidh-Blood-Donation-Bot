# بوت مُنقذ للتبرع بالدم في العراق 🩸🇮🇶

**مُنقذ** هو بوت تيليجرام إنساني يهدف لتسهيل عملية التبرع بالدم في العراق من خلال ربط المتبرعين بالمحتاجين بشكل فوري ومنظم حسب المحافظة وفصيلة الدم.

## المميزات الرئيسية
- 📝 **تسجيل المتبرعين:** إمكانية تسجيل البيانات (الاسم، الهاتف، فصيلة الدم، المحافظة) بسهولة.
- 🔍 **البحث الذكي:** البحث عن متبرعين حسب فصيلة الدم والمحافظة بضغطة زر.
- 👤 **عرض البيانات:** يمكن للمتبرع استعراض بياناته المسجلة في أي وقت.
- ❌ **الخصوصية:** إمكانية حذف البيانات نهائياً من قاعدة البيانات بطلب من المستخدم.
- 📱 **واجهة سهلة:** استخدام أزرار تفاعلية بدلاً من الأوامر النصية المعقدة.

## المتطلبات التقنية
- Python 3.7+
- aiogram 2.25.1
- SQLite3 (مدمج مع بايثون)

## طريقة التشغيل
1. قم بتحميل الكود أو عمل `git clone` للمستودع.
2. قم بتثبيت المكتبات اللازمة:
   ```bash
   pip install -r requirements.txt
   ```
3. ضع توكن البوت الخاص بك في ملف `main.py` في متغير `API_TOKEN`.
4. قم بتشغيل البوت:
   ```bash
   python main.py
   ```
